# Heft

Handschriftliche Notizen und PDFs im Browser – für Windows-PC, Laptop und iPad (als App installierbar).

- Notizbücher mit Cover, Ordner, Papiervorlagen (leer, liniert, kariert, Punkte, Cornell; weiß/creme/dunkel)
- Stift mit Druckstärke (Apple Pencil), Textmarker, Radierer, Lasso (verschieben, skalieren, kopieren), Formen, Text, Bilder
- PDFs öffnen und beschriften, alles als Vektor-PDF exportieren
- Daten bleiben im Gerät (IndexedDB), offline nutzbar

Enthält pdf.js (Apache-2.0, Mozilla) und pdf-lib (MIT) in `vendor/`.
